### projects

**[blackjack-tcp](https://github.com/Hazy2006/blackjack-tcp)** `shipped`
Multiplayer Blackjack over raw TCP — a single-threaded `select()` server in Python hosting players from C on Linux, Java on Windows and Kotlin on Android, over a hand-written line protocol. Multiplexing, processes and threads in one project.

**[PitWall](https://github.com/Hazy2006/PitWall)** `active`
F1 championship predictor in C++ — a Markov-chain grid → finish model and a Bayesian (Dirichlet) per-driver model, fed into a 10,000-run Monte Carlo season simulation over real 2024 results. Graph engine and a raw SQLite data pipeline.

**[Magnetica](https://github.com/Hazy2006/Magnetica)** `shipped`
Interactive 2D charged-particle simulator in Python — dual physics modes (magnetic Lorentz force and orbital attraction), live orbit analysis, and from-scratch numerical integration.

**[gomoku-ai](https://github.com/Hazy2006/gomoku-ai)** `shipped`
GUI Gomoku game with a minimax AI opponent, alpha-beta pruning, and 3 difficulty levels.

**BBU lab series** `ongoing`
Fundamentals, OOP, DSA, and Graphs coursework in C, C++ and Python — layered architecture, ADTs, graph algorithms, shell scripting. All public.
